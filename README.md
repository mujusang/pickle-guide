# 크랩아카데미 특강 자료 — 질문하는 챗봇을 넘어 '일해주는 비서'로

2026년 11월 18일 크랩아카데미 특강(주관 신동선 박사, 강사 박종익 원장) 수강생에게 공유하는 공개 페이지입니다.

- 페이지: https://mujusang.github.io/pickle-guide/
- 구성(위에서 아래로):
  1. 주관·강사 — 신동선 박사 / 가온자리한의원 박종익 원장
  2. 핵심 메시지 — 파레토 법칙의 현실화, 자그맣게 피드백 무한반복, 상상력이 최고의 지능, 피클은 여의주
  3. 핵심 자료 & 다시 보기 — 기업설명 노션, 오늘 강의 노션, 유튜브 다시 보기(각 링크 연결 대기 자리)
  4. 특강 핵심 요약 → 피클 따라 하기(시작 4단계·노션 루틴·팁) → 보안과 신뢰 5축
  5. 주관 신동선 박사 — 프로필, 네이버 블로그, 크랩아카데미, 대표 도서 판매 링크
  6. 참고 링크
- 릴레이 초대판(구글 시트, 링크 아는 사람 누구나 편집): https://docs.google.com/spreadsheets/d/1rLR3R0zg5aKBpXSuy3CuYx9RkSnfMuSmg30Wx8ro2RM/edit
- 파일: `index.html` 단일 문서(외부 라이브러리 없음, 모바일·카톡 인앱 브라우저 기준)

개인정보, 환자 정보, 계정·비밀번호, 내부 운영 규칙은 담지 않았습니다.
